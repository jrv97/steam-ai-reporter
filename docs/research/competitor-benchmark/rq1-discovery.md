### AI Slop Filter for Steam

- The article rq4 cited (https://helpfulinfoforyou.com/2026/07/steam-ai-filter-browse-and-hide-generative-ai-games/, byline "Helpful Info", 2026-07-01) does not name "AI Slop Filter for Steam" or any extension; it calls its subject "the AI warning plugin" and credits GamingOnLinux (https://www.gamingonlinux.com/2026/06/the-ai-warning-for-steam-browser-plugin-adds-steam-search-filtering/). The earlier summary of that page was wrong.
- No store or repo carries that exact name: a web search for the exact string (2026-10-21), AMO API searches, Edge Add-ons searches, GitHub repository and code searches, Greasy Fork (319 scripts for steampowered.com read) and ChromeBoard searches returned nothing.
- A Chrome Web Store item "AI Slop Filter" (https://chromewebstore.google.com/detail/iadgbaofmeldcmhogdpemkndldjkbnbc) appeared in search. The ExtScope tracker page for that ID describes it as "Hides LinkedIn AI slop", host access `linkedin.com`, 139 users, v0.4.0, no mention of Steam (https://extscope.org/extension/iadgbaofmeldcmhogdpemkndldjkbnbc, 2026-10-21). The Web Store page itself could not be opened (see section c).
- Result: cannot find "AI Slop Filter for Steam". The only "AI Slop Filter" found is a LinkedIn tool. The nearest real Steam tools are Steam Slop Filter (dunkbing) and Slop-Inator (Dysnomia), both created in the week of 2026-10-16. A Steam-specific tool of that name may exist on the Chrome Web Store only, where the search could not be run.
