Tag order

Tags at the top have priority: badges, banners and summaries list tags in this order, and where room is short the first ones take it. The settings tabs and the popup follow the same order.

Only the first 2 tags fit on game images and search suggestions; the rest go into "+N". Only the first 3 tags fit on search, wishlist and DLC rows; the rest go into "+N".

Drag a tag by its handle, or click the handle and then the handle of the place it goes to. With a keyboard, Space or Enter picks a tag up, the arrow keys move it, Space or Enter drops it and Escape puts it back.
