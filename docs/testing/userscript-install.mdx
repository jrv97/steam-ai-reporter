# Installing the userscript for testing

The userscript is `dist/userscript/steam-ai-reporter.user.js`, written by `mise run build`. A userscript manager runs it on every `https://store.steampowered.com/*` page. Test in Chrome and in Firefox Nightly only; the regular Firefox is personal and stays untouched.

Run `mise run build` first. The file lives in your clone, for example `C:\Users\you\Documents\dev\steam-fuck-slop\dist\userscript\steam-ai-reporter.user.js`.

## Tampermonkey

1. Install Tampermonkey in Chrome (Chrome Web Store) or in Firefox Nightly (addons.mozilla.org).
2. Chrome only: open `chrome://extensions`, click Details on Tampermonkey, turn on "Allow access to file URLs". Also turn on "Allow User Scripts" if Chrome shows that switch.
3. Open the built file in a tab by its `file:///` address, for example `file:///C:/Users/you/Documents/dev/steam-fuck-slop/dist/userscript/steam-ai-reporter.user.js`.
4. Tampermonkey shows an install page. Check that the name is "AI Reporter for Steam" and that the permissions list only storage access and a menu command (no network access to other sites). Click Install.
5. To update after a rebuild, open the same `file:///` address again and click Reinstall.

## Violentmonkey

1. Install Violentmonkey in Chrome (Chrome Web Store) or in Firefox Nightly (addons.mozilla.org).
2. Chrome only: open `chrome://extensions`, click Details on Violentmonkey, turn on "Allow access to file URLs".
3. Open the built file by its `file:///` address in a tab, as above.
4. Violentmonkey shows "Confirm installation". Tick "Track local file" so it reloads the script from disk while that tab stays open, then click Confirm.
5. After a rebuild, switch to that tab and reload it; Violentmonkey picks up the new file.

Use only one manager at a time on a given browser, or disable the other one for the test, so the script runs once.

## What you should see

Open each page logged out first, then logged in. The first page load after installing may need a refresh.

1. App page `https://store.steampowered.com/app/5072580/` (Courage and Faith: Into the Dark Woods, discloses): a purple banner above the purchase box titled "The developer discloses AI use", quoting the developer's text, and a "Disclosed by the developer" chip under Developer and Publisher.
2. App page `https://store.steampowered.com/app/413150/` (Stardew Valley, does not disclose): nothing added.
3. Search page `https://store.steampowered.com/search/?term=roguelike`: an "AI use disclosed" badge before the platform icons on the rows whose developers disclosed (about ten of the first fifty at the time of writing), and nothing on the other rows.
4. Settings: click the manager's toolbar icon, then "AI Reporter for Steam", then "Settings". A dialog titled "AI Reporter for Steam" opens with switches for badges and banner, a Show, Dim or Hide choice, and a list of games you stopped marking. Escape or Close closes it and returns focus to the page. Change "Games that disclose AI use" to Hide on the search page: the badged rows vanish at once.
5. Disable the script in the manager and reload: every added element is gone.
