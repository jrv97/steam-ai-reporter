## 2026.11.10.1 - 2026-11-10
### Added
- The toolbar popup and the userscript settings show how far the tags of the open store page have loaded: how many games have an answer, a countdown while Steam limits requests, and how many games got no answer.
- The settings have a Lookup results card that shows how many games Tag Kit keeps what Steam said about, and can clear them all or only the games Steam gave no answer for, so store pages look them up again. A Reset card puts every setting back to its default or stops ignoring every game, developer and publisher, each after a check that lists what changes.
### Changed
- The Go back to Steam button on the All Settings page now reads Go back, after an arrow icon. When the tab you opened the settings from is gone, it closes the settings tab if the window holds other tabs, and opens the Steam store only when the settings tab is alone. The backup buttons start with file icons.
### Fixed
- On a page full of games that Tag Kit has not seen before, such as the store home page, tags now appear in groups as Steam answers each batch of games, instead of all at once after the last batch.
